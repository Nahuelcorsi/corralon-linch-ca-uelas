# Materiales Lynch — web

Sitio estático (HTML + CSS + JS, sin build) del corralón Materiales Lynch, Cañuelas.

- Datos a completar del cliente (dirección, horarios, mapa, fotos): bloque `CONFIG` al inicio de `js/main.js`.
- Para probar localmente: `python -m http.server 5173` y abrir http://localhost:5173
- Publicación: GitHub Pages desde la rama `main`, carpeta raíz.
